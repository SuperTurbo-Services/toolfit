# Set up Playwright

Runs browser automation and end to end tests.

This connector is not carried inside the Toolfit plugin. Add it once in your own account after the skills are installed.

## Setup

1. Open Local, over stdio.
2. Find or add Playwright, then sign in with the account you want to use.
3. Review the requested permissions before approving access.
4. Test it on one low-risk folder, workspace, or account before expanding access.

## First use

Ask your AI app to use Playwright for one small task related to this workflow: Runs browser automation and end to end tests.
Confirm it can see only the account, workspace, or files you intended before using it on live work.

Start read-only whenever that option exists. Refuse write access unless the workflow genuinely needs it.
